# PRODUCT.md

## FluxBar: Статус-бар нового поколения на Rust
**Слоган**: *Молниеносный. Безопасный. Абсолютно кастомизируемый.*

### 1. Видение и проблема
Существующие решения (например, SketchyBar) обладают мощной концепцией, но имеют архитектурные ограничения: они сильно зависят от выполнения shell-скриптов при каждом событии. Это создает значительные накладные расходы на `fork/exec`, ограничивает типизацию данных, усложняет отладку и делает систему уязвимой к ошибкам в сторонних скриптах.

**FluxBar** решает эту проблему, предлагая ядро на Rust с событийно-ориентированной архитектурой и современной системой плагинов. Мы поддерживаем как легковесные постоянные процессы (через IPC), так и изолированные WebAssembly-модули, сохраняя при этом полную гибкость концепции "бар как код" (Configuration as Code).

### 2. Целевая аудитория
- **Разработчики и Power Users**: Пользователи macOS (и в перспективе Linux/Wayland), использующие тайловые оконные менеджеры (yabai, Aerospace, Hyprland) и ценящие контроль над своим рабочим пространством.
- **Авторы плагинов**: Разработчики, желающие создавать надежные дополнения на знакомых языках (Rust, TypeScript, Python, Lua) без боли с парсингом аргументов командной строки и shell-хуками.
- **Энтузиасты кастомизации**: Пользователи, которым важны плавные 60+ FPS анимации, нативная интеграция и нулевое потребление ресурсов в простое.

### 3. Ключевые возможности (Features)
- **Полная динамическая кастомизация**: Добавление, удаление и изменение любых элементов (иконки, текст, графики, аллиасы системных приложений) в реальном времени без перезапуска бара.
- **Событийно-ориентированная шина (Event Bus)**: Встроенные системные события (`space_change`, `media_change`, `mouse.entered`) и поддержка кастомных событий (`fluxbar --trigger build_finished`).
- **Умная система плагинов**:
  - Поддержка постоянных соединений (Unix Domain Sockets / stdin/stdout) для устранения задержек `fork/exec`.
  - Официальные SDK для Rust, Python и TypeScript.
  - Песочница для community-плагинов через WebAssembly (Wasm).
  - Встроенный менеджер плагинов (`fluxbar plugin install <repo>`).
- **Продвинутый рендеринг**: Поддержка Nerd Fonts, SF Symbols, сглаженных графиков, градиентов, прозрачности (blur) и интерполяции анимаций.
- **Полная интерактивность**: Нативная поддержка мыши (click, scroll, enter, exit) с привязкой к действиям, скриптам или IPC-сообщениям.

### 4. Архитектура высокого уровня
1. **Ядро (Core)**: Асинхронный цикл событий на базе `tokio`, управляющий состоянием бара, логикой анимаций и рендерингом.
2. **IPC-слой**: JSON-RPC через Unix Domain Sockets для двусторонней, типизированной связи с плагинами и CLI-утилитой.
3. **Рендерер**: Абстрагированный слой рендеринга. Для macOS: нативная интеграция через `objc2` + Core Animation (для идеальной работы с NSStatusItem). Для кроссплатформенности: `wgpu` + `cosmic-text`.
4. **Plugin Host**: Менеджер жизненного цикла плагинов, который запускает, мониторит состояние, изолирует сбои и автоматически перезапускает упавшие процессы.

### 5. Ценностное предложение (Почему FluxBar?)
| Проблема SketchyBar | Решение FluxBar |
| :--- | :--- |
| Накладные расходы на `fork/exec` при каждом тике | Persistent-плагины с постоянным IPC-соединением (0 мс оверхеда на запуск) |
| Нетипизированные строковые аргументы в shell | Строгий JSON-RPC контракт с валидацией через `serde` |
| Падение скрипта может сломать логику бара | Изоляция сбоев: Plugin Host перезапускает упавший плагин без влияния на ядро |
| Сложность распространения плагинов | Встроенный CLI-менеджер пакетов и поддержка Wasm-песочницы |
